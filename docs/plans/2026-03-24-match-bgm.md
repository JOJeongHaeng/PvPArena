# Match BGM Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add phase-driven local background music that uses `Starter_Music_Cue` outside combat and `Starter_Background_Cue` during gameplay without restarting the non-combat track between `Lobby` and `MatchEnd`.

**Architecture:** Extend `UPvPArenaHUDWidget` with one local music audio component and two default sound assets. Reuse the widget's existing `RefreshWidgetData()` phase polling, derive the desired track from `APvPArenaGameState::GetMatchPhase()`, and only swap tracks when the desired cue changes.

**Tech Stack:** Unreal Engine 5 C++, `UUserWidget`, `UAudioComponent`, `USoundBase`, replicated `GameState`, Unreal automation tests.
