# IP Multiplayer UI Design

## Goal

패키징 빌드에서도 콘솔 없이 원격 멀티플레이를 시작할 수 있도록, 로비 상단 패널을 `Host Match` / `Join By IP` 흐름으로 바꾼다.

## Scope

- 상단 로비 패널에 연결 상태 텍스트, IP 입력칸, `Host Match`, `Join By IP`, 기존 `Ready` 버튼을 배치한다.
- 하단 로비 패널은 키보드/마우스 조작 설명 카드만 유지한다.
- 버튼 클릭 시 내부적으로 `open` 명령을 실행해 listen 서버 생성과 직접 IP 접속을 수행한다.
- 기존 EOS 로그인/세션 버튼은 로비 UI에서 제거한다.

## Notes

- 현재 목적은 포트폴리오용 원격 플레이 테스트라서 EOS 로그인 흐름보다 직접 IP 접속이 우선이다.
- 패키징 빌드에서 콘솔이 없어도 버튼만으로 접속할 수 있어야 한다.
